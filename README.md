# Telo.Sabe — сайт telosabe.com

Статический сайт на трёх языках: русский (`/`), испанский (`/es/`) и английский (`/en/`).
Сборщик не нужен: это готовые HTML, CSS и JS файлы, их можно сразу выкладывать на GitHub Pages.

## Структура

```
index.html            русская версия
es/index.html         испанская версия
en/index.html         английская версия
assets/css/site.css   стили
assets/js/site.js     меню, вкладки услуг, отзывы, вопросы, просмотр сертификатов
assets/img/           фото, сертификаты, скриншоты отзывов, рукописные подписи
assets/fonts/         шрифты Jost и Cormorant Garamond (лежат локально, без запросов к Google)
404.html              страница «не найдено»
CNAME                 домен telosabe.com для GitHub Pages
robots.txt, sitemap.xml, favicon.svg
_build/               тексты сайта (content.py) и скрипт сборки (build.py)
```

## Как выложить на GitHub Pages

1. Создай на github.com новый репозиторий, например `telosabe-site`. Тип — **Public**: на бесплатном тарифе Pages работает только с публичными репозиториями.
2. Загрузи туда всё содержимое этой папки: кнопка **Add file → Upload files**, перетащи все файлы и папки, затем **Commit changes**.
   Файлы `.nojekyll` и `CNAME` тоже нужны. На Mac файлы, начинающиеся с точки, скрыты: в Finder их показывает сочетание `Cmd + Shift + .`.
3. В репозитории открой **Settings → Pages**. В блоке **Source** выбери **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем **Save**.
4. В том же разделе, в поле **Custom domain**, должно стоять `telosabe.com` (оно подтянется из файла CNAME). Когда проверка DNS пройдёт, включи **Enforce HTTPS**.
5. Настрой DNS у регистратора домена telosabe.com:
   - четыре записи **A** для `@`: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`;
   - запись **CNAME** для `www` → `<твой-логин>.github.io`.

   Старые записи A и CNAME, которые ведут на прежний хостинг, нужно удалить. Обновление DNS занимает от нескольких минут до 24 часов.

## Как поправить текст

Все тексты лежат в `_build/content.py`, по разделам и языкам. После правки запусти из корня папки:

```
python3 _build/build.py
```

Скрипт заново создаст `index.html`, `es/index.html`, `en/index.html` и `sitemap.xml`. Изменённые файлы загрузи в репозиторий.
Небольшую правку можно сделать и прямо в HTML-файле, но тогда при следующей сборке она перезапишется. Поэтому лучше править `content.py`.

## Что сделать до запуска

- [ ] **Юридические страницы.** На старте ссылок на них в подвале нет. Когда тексты Aviso legal, Политики конфиденциальности и Cookies будут готовы (с именем, NIF и контактом, лучше согласовать с asesor), их нужно добавить в подвал: место отмечено комментарием TODO в `_build/build.py`.
- [ ] **Лицензия шрифта Eskal** (рукописные подписи). Шрифт скачан с ofont.ru: проверь, что его можно использовать на коммерческом сайте. Если нельзя, подписи можно заменить картинками своего почерка.
- [ ] **Переводы.** Испанскую и английскую версии лучше показать носителю языка: тексты услуг, вопросов и переводы отзывов. Переведённые отзывы на сайте помечены «traducido del ruso» / «translated from Russian».
- [ ] **Рукописные подписи** набраны шрифтом Eskal (встроен в `assets/css/site.css`). В нём нет испанских букв с ударением и знака «¡», поэтому испанские подписи написаны без них.
- [ ] Проверь сайт на телефоне после публикации.
